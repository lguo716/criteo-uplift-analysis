# 阶段9：独立讲解与求职表达

目标：在面试中把业务问题、方法选择和真实结果串起来。

先读reports/findings.md、interview_guide.md和resume_bullets.md。用一分钟说清：广告后发生的结果不全是广告带来的；使用公开随机分组样本；将实验推断、增量排序和预算决策连起来；模型并未超过响应基准。

再用五分钟解释数据身份与抽样、曝光为何排除、95%率差区间、S/T/X区别、固定验证选择、处理比例校正和配对Bootstrap。最后说预算结果与真实性边界。

你的优势是完整可复现与严谨比较，不是堆模型名。回答“模型没赢怎么办”时，说明你保留简单基准优势，并建议新实验验证候选。不要把离线效果写成上线收入提升。

简历三条分别覆盖数据规模与质量、统计/模型方法、验证后的策略结果。Power BI最终状态以验收文档为准，尚未验收的PBIX不能写成完成。

自测：不看文档，解释一次绝对百分点与相对提升；手算一次85%/15%校正；说明为什么个体效果无法直接观察；给出下一轮真实实验需要补充的成本与指标数据。

通过标准：能独立运行分阶段命令、指出实际结果表和代码位置、说清假设及局限，不把匿名数据编成企业落地案例。
