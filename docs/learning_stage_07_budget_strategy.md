# 阶段7：预算策略与业务建议

目标：在同样触达规模下比较随机、响应排序与增量排序。

预设预算5%、10%、20%、30%、50%、70%、100%，默认20%。全量只对应100%成本，不投放对应0%。随机使用期望qG(1)，不能挑一个表现碰巧较低的随机样本当对照。

在60万独立测试样本上，20%访问情景：每万名候选用户增量访问估计，随机21.07次，S-Learner89.59次，响应排序97.28次。S相对随机多68.52次，配对95%条件区间约[59.92,77.12]；S相对响应少7.69次，区间约[-13.22,-1.50]。

结论：定向排序优于随机，但当前S模型没有超过简单响应基准。下一步把响应与Uplift作为候选，在新实验中验证；不能宣称“因果模型必然优于预测模型”。

单位触达成本归一化为1；20%触达的每万候选人成本为2000个归一化单位。没有真实金额或收入，不能写真实ROI或企业收益。预算效率是离线假设下的比较。

十分位只代表评分层级。无法确认单个用户反事实类型，也不能把匿名特征编造成年龄、地区等画像。

证据：budget_strategies.csv、decile_profiles.csv、05_budget_strategies.png。
