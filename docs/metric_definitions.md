# 指标与评估口径

## 实验和观察单位

每行是发布者描述的一条匿名用户实验记录。`treatment=1`是允许被广告投放的随机分组，`treatment=0`是控制组；不是“实际看过广告”和“没看过广告”的比较。`exposure`是在分组后是否真的曝光的描述字段，禁止用于筛选实验分析样本、定义处理或模型特征。

`visit`、`conversion`分别表示分组后两周内是否访问、转化。访问是预设主指标，转化是探索性辅助指标。结构约束为控制组没有曝光、无访问没有转化。

## 发生率、率差、相对提升

- 发生率 = 组内结果为1的人数 / 该组人数，包含未实际曝光的实验组成员。
- 绝对差 = 实验组发生率 − 对照组发生率；乘100后是**百分点**。
- 相对提升 = 绝对差 / 对照组发生率；对照组发生率为0时不定义。
- 组发生率采用95% Wilson区间，率差采用95% Newcombe hybrid score区间。
- 相对提升区间先对风险比RR=实验率/对照率做log尺度正态近似：`SE(log RR)=sqrt(1/a−1/n_t+1/c−1/n_c)`，指数变换后减1；任一组零事件时不定义该有限区间，也不擅自补0.5。完整四类区间见[experiment_effect_intervals.csv](../reports/tables/experiment_effect_intervals.csv)。计算与[statsmodels官方风险比方法](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.Table2x2.riskratio_confint.html)一致；这是相对变化区间，不能用率差区间直接除以固定对照率替代。
- 两比例检验p值只用于补充；极小p值不等于业务效果大。访问为预设主要推断，转化属于探索性结果，不将其解释为独立确认性检验。

公开数据经过非均匀标签抽样，无法恢复原始活动的发生率或真实增量规模。“ATE”在本项目是公开基准的组间率差记号。

## 特征与平衡

论文表2定义连续特征为`f0/f2/f7/f10`，其余为匿名类别token。类别的浮点值没有自然大小含义，用训练集类别字典映射；未见类别按缺失处理，不把浮点token截断为整数。连续变量使用绝对SMD，类别使用总变差距离`½Σ|p_t(k)−p_c(k)|`。两者量纲不同，0.1只作为描述性参考。

公开处理比例约85%/15%，不是50%/50%。缺少原始分流方案，不能用四舍五入的85%作严格SRM结论；特征平衡也不能证明随机化一定正确。

## 模型和数据隔离

按处理、访问、转化的联合标签分层随机划分60%/20%/20%。种子42；训练集180万，验证集60万，测试集60万。类别字典只在训练集拟合。模型输入仅`f0`—`f11`，禁止`exposure/visit/conversion/row_id/split`。

S模型输入另外包含作为干预参数的`treatment`，预测时人为分别设为1和0，取两个预测之差。这不等于用未来实际曝光作为特征。

T-Learner分别拟合处理组和控制组响应概率。X-Learner对控制组构造`μ1(X)−Y`，对处理组构造`Y−μ0(X)`，分别拟合效应回归，再用训练处理比例`p`组合为`pτ0+(1−p)τ1`。另一组响应模型不会看到被用于其伪标签的本组结果。

早停使用验证损失，元模型按验证Qini选择。响应模型不输入处理变量，只用于普通响应概率排序对照。始终保留响应基准的效果，即使其优于Uplift模型。特征重要性来源于响应模型，表示预测关联，不能解释为特征的因果作用。

## 累计增量、Qini与AUUC

在一个评估集中，`N`是总人数、`p`是整个评估集的处理比例，固定用于其所有Top-K点：

`Z_i = Y_i [T_i/p − (1−T_i)/(1−p)]`

`G(q) = Σ(评分最高的 floor(qN) 人) Z_i / N`

分母始终是整个候选人群N。`G(q)`乘10,000是“每万名候选用户的预计增量次数”。`G(q)/q`是每名目标用户的平均增量估计；q为0时效率不定义。

`AUUC = ∫₀¹G(q)dq`

`Qini = ∫₀¹[G(q)−qG(1)]dq`

积分使用0%—100%的101点梯形法。随机策略使用期望`qG(1)`，不挑选一个碰巧表现好的随机种子。100%预算时各模型必须达到同一评估集的两组率差；不能与300万总样本的率差混为一谈。

评分相同时用源行号的固定哈希打散，不依赖结果标签，不偏向原始文件顺序。这里row_id只用于定位和独立的平局处理，未作为模型特征。

## Bootstrap与不确定性

500次处理组内多项式重抽样；每次保持两组人数。所有模型共享同一次抽样权重，因此模型与随机、模型与响应的差异是**配对区间**。结果为2.5%与97.5%分位数。

只有结果为1的行影响Z的分子；结果为0的行可合并为剩余多项式类别，和对整个处理组逐行重抽样的分子分布完全一致。这是精确聚合，不是Poisson近似。

区间以已经训练的模型及原评估集固定Top-K成员为条件；不重新训练模型，也不覆盖全部模型选择、阈值估计、跨活动相关性和上线漂移的不确定性。置信区间不是“模型有95%概率真实有效”。

## 策略与预算

预算预设为5%、10%、20%、30%、50%、70%、100%，默认展示20%。不投放对应0%；全量投放只对应100%，不能拿它在100%成本下的绝对效果与20%成本策略宣称同成本胜出。

单位触达成本假设为1，归一化成本=10,000q；效率=1,000G(q)/q。没有收入、实际广告成本、转化金额，故不计算真实ROI或企业收益。

十分位组是评分层级；公开数据无法观察个体两个潜在结果，不能把某个用户确认为“被说服者”“负向响应者”，也不能给匿名特征编造年龄、收入等含义。
