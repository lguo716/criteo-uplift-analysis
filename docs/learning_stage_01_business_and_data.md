# 阶段1：业务问题与数据

目标：解释“本来就会访问”与“因为广告才访问”的区别。

先读README和data/README，检查data/source_manifest.json。官方v2.1包含约1,398万条用户实验记录，12个处理前匿名特征、随机分组、访问、转化、实际曝光。结果观察期是分组后两周；数据没有日期、收入、真实成本或可解释的人口属性。

实际入口：`python -m src.learn --stage 1`。重新获取数据：`python -m src.run_pipeline --stage download`；程序将检查文件大小及SHA256。

必须讲清：treatment是随机允许投放，exposure是实际曝光。前者定义实验处理，后者只能描述。发布者做了非均匀抽样，所以无法恢复原活动真实收益。

复盘问题：转化率高的人群为什么不一定增量高？为什么控制组也可能访问或转化？没有真实成本时还能回答哪种预算问题？
