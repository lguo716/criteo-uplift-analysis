# 阶段3：实验增量推断

目标：把业务问题转成两组发生率及率差。

执行：`python -m src.run_pipeline --stage experiment`；Notebook为notebooks/01_experiment_analysis.ipynb。核心方法在src/experiment.py。

访问处理组123,523/2,550,075=4.8439%；控制组17,054/449,925=3.7904%。绝对差1.0535个百分点，相对提升27.7935%。95% Newcombe率差区间约[0.9914,1.1149]个百分点。

转化处理组7,795/2,550,075，控制组874/449,925；绝对差约0.1114个百分点。它是探索性辅助指标。组率使用Wilson区间；率差使用Newcombe，不能把两组区间简单相减。

所有随机处理组成员进入分母，包括没有实际曝光的人。这种比较保留随机分组含义，而按曝光筛选会引入处理后选择。

这里的差异限于公开基准样本。发布者的非均匀标签抽样改变原活动水平，不宣称这些数值是广告主实际增量。

证据：experiment_summary.csv、experiment_groups.csv和01_experiment_rates.png。
