# 阶段4：特征平衡与因果边界

目标：检查随机组在处理前特征上的可比性，并说明检查能与不能证明什么。

读reports/tables/feature_balance.csv和category_balance.csv。连续f0/f2/f7/f10用标准化均值差SMD；其余是匿名类别，比较类别比例并计算总变差距离。类别token是浮点值，没有自然顺序。

本次连续绝对SMD最大约0.0184；所有描述差异都低于参考线0.1。类别总变差与SMD量纲不同，0.1是项目描述性约定，不是一个可证明随机化正确的统一统计检验。

实际分组约85%/15%。原实验分流配置未公开，不能把四舍五入的85%当精确设计比例，再宣称正式SRM通过。也不能要求1:1。

曝光、访问、转化发生在处理后，不属于平衡检查的处理前协变量。特征重要性也不意味着改变这个匿名特征会导致访问变化。

证据：04_feature_balance.png、docs/metric_definitions.md。
