# 阶段2：质量检查与抽样

目标：从完整文件构造可重现、具有明确观察单位的分析样本。

执行：`python -m src.run_pipeline --stage prepare --sample-size 3000000 --seed 42`。读src/data.py和reports/tables/data_quality_checks.csv。程序一次扫描全量约1,398万行，检查缺失、非有限数值、非二元标签、控制组曝光、无访问转化及行数。

抽样不是取前300万行。先在全部源行位置里不放回均匀选择，再扫描文件抽取这些位置。每条记录入选概率相同；固定种子和位置指纹用于复核。

row_id是位置，不是用户ID。匿名特征相同不等于同一用户，故保留相同记录并报告数量。本次样本有71,981条完全相同匿名特征与标签的重复位置，未自动删除。

按处理、访问、转化联合标签分层，得到180万训练、60万验证、60万测试。标签只用于分层和结果分析，不是模型特征。验证/测试的身份位置互斥，但缺少公开用户标识，不能保证跨实验用户身份互斥。

证据：data/sample_manifest.json、reports/tables/split_counts.csv。
